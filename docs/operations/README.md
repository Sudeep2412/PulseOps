# PulseOps Operations Manual

This directory contains standard operating procedures (SOPs), deployment checklists, demonstration scripts, and operational governance documentation for the PulseOps platform.

## Contents
- [Deployment Checklist](deployment_checklist.md): Step-by-step pre-flight, execution, and verification checklist for production releases.
- [Production Readiness Review](production_readiness.md): Production readiness scorecard across architecture, security, observability, and operations.
- [Demonstration Guide](demo_guide.md): 15-minute scripted presentation walkthrough for evaluators, stakeholders, and interviewers.
- [Project Handover](project_handover.md): Operational ownership guide, secrets rotation procedures, and maintenance lifecycle.
